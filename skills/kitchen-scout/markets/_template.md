# Market: <name>

## Local palate vector
Which way kitchens here drift dishes for local customers: sweetness, heat, dairy/cheese, portion size, bread, oil. This vector is what chef notes have to push against.

## Counter and line languages
Who reads the ticket first, and which languages the kitchen staff actually speak. These can differ from the cuisine's language. This decides line 3 of the chef notes, and sometimes adds a line.

## Platforms (as of YYYY-MM; re-verify after 6 months)
The dominant delivery apps, **per country** if the file covers several. List recent exits explicitly. No share percentages. All are driven via `platforms/_browser.md`; add `platforms/<app>.md` field notes if one exists.

## Proxy flips

## Hard-filter notes
Local realities that affect dietary filters (pork availability, how halal is certified, alcohol in cooking, labeling norms).

Hubs: give at least 2 cities per country where possible, not only the capital.

## Gaps
