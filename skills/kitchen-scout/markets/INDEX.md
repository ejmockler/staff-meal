## No file for this market? Derive one (≤10 min), and offer to save it
1. **Palate vector**: look at how the local mainstream chains alter global dishes (the local pizza toppings, the McDonald's specials, what "spicy" means on menus). That's the direction proxies drift.
2. **Who cooks what**: identify the largest immigrant communities, and which ones run the restaurant trade. Large communities often run kitchens for cuisines other than their own.
3. **Proxy test** for each candidate kitchen: does the menu span several countries (South Asian + Thai + sushi)? Are the dishes identical across "different" cuisines? Do the reviews come in the cuisine's language?
4. **Languages**: the counter language plus the line cooks' languages.
5. Write it with `_template.md`, mark it `(derived, unverified)`, and add it to this index.

Confidence: these market files are a model's synthesis of widely reported patterns. Neighborhood hubs shift over time, so treat them as search leads, not facts.
